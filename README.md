# White Lightning (working title) — Unity Edition

Self-directed, tactile distilling process sim with a first-person 3D workshop.
Run a small off-the-books still, sell jars out the back of restaurants for cash,
grind toward a license + legal facility. Reference points: Car Mechanic
Simulator, PowerWash Simulator — low-stakes craft-mastery loop; the early
illegality is texture, not danger (no busts, no heat meter).

- `docs/design-doc.md` — full design spec (systems, workshop tiers, tone)
- `docs/project-plan.md` — milestones + current state; **we're on Milestone 1**
- `docs/distillation-reference.md` — process knowledge base (sources reconciled)
  and a synthesised still-run simulation model (§9) to drive `StillRunController`

## Getting started

1. Install **Unity 6000.0.36f1** (or the nearest Unity 6 LTS — 6000.5.x has been
   used for development) via Unity Hub. First open imports the packages in
   `Packages/manifest.json` (URP, VFX Graph, TextMeshPro, Input System, Timeline)
   and can take several minutes.
2. Open `Assets/Scenes/Prototype.unity` and press **Play**. First-person walk
   (WASD, mouse look, Shift sprint, Space jump, Esc frees the cursor); walk to
   the still, look at a white block, press **E** to start the run and make cuts;
   press **Tab** for the batch clipboard.

### Rebuilding the prototype from scratch

Scenes and props are generated by editor scripts (menu **Tools > White
Lightning**), not hand-authored — keeps them reproducible. Run in order:

| Step | Menu item | Result |
|---|---|---|
| 1 | Set Up URP Pipeline | Creates + assigns `Assets/Settings/URP-Pipeline.asset` (one-time; the project shipped without one) |
| 2 | Build Prototype Scene | `GameState` + `Still` + Canvas + prototype UI → `Assets/Scenes/Prototype.unity` |
| 3 | Build Basement Room **or** Build Outdoor Sandbox | Swappable greybox environment root into the active scene |
| 4 | Add First-Person Player | CharacterController rig; reuses the Main Camera as the eye |
| 5 | Add Still Interaction Rig | White-block controls + look-at HUD; authors the `proofCurve` AnimationCurve on `StillRunController` |
| 6 | Add Clipboard | Toggleable (Tab) job checklist + live data HUD |

After a fresh URP setup, import each asset pack's bundled `*_URP_*.unitypackage`
and run **Window > Rendering > Render Pipeline Converter** (Built-in → URP,
Material Upgrade) for anything still magenta. See
`docs/project-plan.md` → Housekeeping.

### Headless / CI build

```
Unity -batchmode -nographics -projectPath . -executeMethod BuildScript.Build -quit
```

Compile-gates until a scene is in Build Settings (`Prototype.unity` is), then
produces a `StandaloneWindows64` player. Args: `-buildTarget`, `-outputPath`,
`-devBuild`.

## What's ported from the Godot/Unreal versions

| Godot | Unreal | Unity | Notes |
|---|---|---|---|
| `game_state.gd` (autoload) | `UMoonshineGameState` (subsystem) | `GameState` (singleton MonoBehaviour) | `GameState.Instance` from anywhere |
| `job_generator.gd` | `UJobGenerator` / `FJobSpec` | `JobGenerator` / `JobSpec` | Static generator, same tuning |
| `still_run.gd` | `UStillRunComponent` | `StillRunController` | MonoBehaviour on the still GameObject |
| `proofing.gd` | `UProofingLibrary` | `ProofingUtility` | Static math, no MonoBehaviour |

Core simulation logic (proof curve, cut scoring, proofing math, clipboard model)
stays plain C#, decoupled from any UI framework.

## Structure

```
Assets/
  Scripts/
    Core/       GameState singleton, JobSpec + JobGenerator
    Gameplay/   StillRunController (centerpiece), ProofingUtility,
                FirstPersonController, Interactable, PlayerInteractor
    UI/         Prototype uGUI wiring (JobBoard/StillRun), ClipboardModel +
                ClipboardController
  Editor/       Tools > White Lightning generators + BuildScript (headless build)
  Scenes/       Prototype.unity (+ generated greybox materials _*.mat)
  Settings/     URP pipeline + renderer assets
Packages/
  manifest.json URP, TextMeshPro, VFX Graph, Input System, Timeline
docs/           design doc · project plan · distillation reference
```

Imported free asset packs (greybox only): BrokenVector LowPolyDungeon, Polytope
Studio, SimpleNaturePack, Toon Gas Station.

## Status

(start run → cuts → result); Milestone 1 focuses on the *feel* of the cut
moment — liquid-stream VFX, steam, sound, a tuned proof curve. Milestone 2
builds the make→sell→cash loop (batch plan → buyer appraisal). The design
spine is **v3: self-directed batches + back-door buyers** — see
`docs/design-doc.md`. Live checklist in `docs/project-plan.md`.
